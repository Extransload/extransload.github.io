# Playroom Renju Worker

정적 Astro 사이트의 오목마루(Omokmaru)와 별도로 배포하는 실시간 대국 서버입니다. `RenjuRoom` Durable Object가 각 방을 맡고 `RenjuLobby`가 공개 방 목록과 빠른 매칭을 직렬화합니다. 착수와 승패는 서버에서 판정하고 WebSocket으로 동기화합니다. AI 싱글 플레이는 브라우저 Web Worker에서 실행되며 이 서버가 필요하지 않습니다.

AI는 같은 렌주 금수 판정을 사용합니다. 쉬움은 상위 후보에서 무작위로 두고, 보통은 전술적 승리·방어를 우선한 위치 평가를 사용합니다. 어려움과 마스터는 각각 제한 시간을 두고 반복 심화, 알파베타 가지치기, 강제 승리 수의 연장 탐색을 수행합니다. 전문 렌주 엔진이나 학습된 평가 모델은 포함하지 않습니다.

## 로컬 실행

프로젝트 루트에서 다음 명령 하나로 Astro와 Playroom Worker가 함께 실행됩니다. 최초 실행 시 Worker 의존성이 없으면 자동으로 설치합니다.

```bash
npm run dev
```

사이트만 실행하려면 다음 명령을 사용합니다. 이 경우 실시간 대국 생성은 동작하지 않습니다.

```bash
npm run dev:site
```

## 배포

```bash
cd renju
npm ci
npm run typecheck
npm run deploy
```

배포된 Worker의 HTTPS origin을 GitHub repository variable `PUBLIC_RENJU_API_URL`에 설정한 다음 공개 사이트를 다시 빌드합니다. Worker 배포와 Pages 배포는 별개입니다. 공유 링크에는 방 ID만 들어가며 플레이어 토큰은 각 브라우저의 localStorage에 보관합니다. 두 번째 접속자는 자동으로 백 자리를 받고, 이후 접속자는 관전합니다.

공개 방은 누구나 목록에서 보거나 빠른 매칭으로 참가할 수 있습니다. 채팅은 참가자와 관전자 모두 사용할 수 있으며 서버에서 200자 제한과 전송 간격을 적용합니다. 임시 영문 이름은 브라우저에 저장하고, 국가와 IP는 Cloudflare 접속 정보에서 얻습니다. 방 저장소와 공개 응답에는 국가와 마스킹된 IP만 남기며, 실제 IP는 현재 접속의 WebSocket 메타데이터에서만 사용합니다.

이름은 로비와 대국 화면에서 바꿀 수 있으며 새 이름은 참가자 표시와 이후 채팅에 반영됩니다. 방장은 대국 시작 전 백 플레이어를 강퇴하거나 관전자를 언제든 내보낼 수 있습니다. 강퇴된 브라우저의 로컬 식별자는 해당 방에서 차단하며, 계정 로그인이 없는 구조이므로 다른 브라우저로 재접속하는 것까지 막지는 않습니다.

오목마루의 돌, 아바타 색, 머리 장식, 바둑판, 승리 연출은 모두 무료입니다. `/playroom/omokmaru/wardrobe/` 꾸미기 스튜디오에서 선택한 항목만 확대해 보는 3D 미리보기, 흑·백 시점, 자동 재생되는 승리 동작, 무작위 조합과 3개의 저장 세트를 이용할 수 있습니다. 선택은 해당 브라우저에 저장되며 로그인, 코인, 구매 API는 없습니다. 대국 화면에서 스튜디오를 새 탭으로 열면 저장된 설정이 진행 중인 대국에도 반영됩니다. AI 및 온라인 대국에서는 자기 돌과 아바타에만 선택한 디자인을 적용하며 상대는 기본 디자인으로 표시합니다. 온라인 방에 외형 설정을 보내거나 다른 참가자의 외형을 반영하지 않습니다. 바둑판 테마도 해당 브라우저 화면에만 적용됩니다.

공개 로비는 방 요약을 별도로 저장하며 목록 요청마다 각 방을 다시 읽지 않습니다. 열린 로비에서만 30초마다 목록을 갱신하고, 탭으로 돌아오면 다시 갱신합니다. 대국 종료 후에는 10초 동안 양쪽의 재대결 수락을 기다립니다. 거절하거나 시간이 지나면 방은 종료 상태로 남아 기보를 볼 수 있습니다.

대기 중 방장이 로비로 나가면 방이 즉시 종료되어 공개 목록에서 사라집니다. 브라우저 종료나 연결 끊김처럼 명시적인 나가기 요청이 없으면 30초 동안 재접속을 기다린 뒤 종료합니다. 대기 중 백 플레이어가 나가면 그 자리만 비워 다시 참가할 수 있습니다. 공개 목록의 방을 누르면 바로 입장하며, 같은 브라우저의 방장 토큰이 유효하면 원래 자리로 돌아갑니다.

대국이 시작되면 흑의 첫 수를 중앙 H8에 자동으로 놓고 백 차례로 넘깁니다. 흑 금수 판정을 사용하는 친선 대국형 렌주입니다. 공식 대회 오프닝 절차인 주형 선택과 색 교환은 제공하지 않습니다. 방장은 기본 시간과 초읽기를 설정할 수 있습니다.
